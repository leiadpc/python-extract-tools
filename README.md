## extract-installer
This script was built on and designed for CachyOS, while it should work on any Linux distro the dependency names may be different
<br>
### Python Dependencies: 
PySide6
<br>
### System Dependencies (on Arch):
ostree: for flatpak<br>
innoextract: for innosetup<br>
cpio: for macOS .pkg and .rpm<br>
xar: for macOS .pkg (from AUR)<br>
rpm-tools: for .rpm<br>
dpkg: for .deb<br>


This is mainly just a unifying tool for extracting installers. Use --gui for the GUI built with PySide6
